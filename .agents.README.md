# Agent Framework Directories

This repository contains several agent/AI-assistant framework directories.
Their status is documented here to avoid confusion.

## Active

| Directory  | Framework                | Status     | Notes                                                                       |
| ---------- | ------------------------ | ---------- | --------------------------------------------------------------------------- |
| `.gaai/`   | GAAI (Governed Agile AI) | **Active** | Documented in `CLAUDE.md`. Canonical AI governance framework for this repo. |
| `.claude/` | Claude Code              | **Active** | Claude Code project settings and memory.                                    |

## Inactive / Archived

| Directory | Framework      | Status       | Notes                                                                       |
| --------- | -------------- | ------------ | --------------------------------------------------------------------------- |
| `.Jules/` | Jules (Google) | **Archived** | Jules AI agent directory. Workflows moved to `.github/workflows/archived/`. |
| `.jules/` | Jules (Google) | **Archived** | Lowercase variant; bolt/palette/sentinel outputs. Patterns gitignored.      |
| `.kiro/`  | Kiro (Amazon)  | **Inactive** | Amazon Kiro AI assistant config. Not actively used.                         |
| `.agent/` | Unknown        | **Inactive** | Legacy agent scaffold. Not referenced in any workflow or CLAUDE.md.         |

## CI Workflows

Jules-\* GitHub Actions workflows have been moved to `.github/workflows/archived/`
as they were causing conflicts by auto-committing to the same branches simultaneously.
The canonical CI pipeline is `.github/workflows/ci-standard.yml`.
