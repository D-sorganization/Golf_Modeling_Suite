# Agent Framework Directories

This repo contains several agent-framework configuration directories.
Only `.gaai/` is the active, governed framework (see `CLAUDE.md` and `.gaai/core/GAAI.md`).

| Directory  | Status                 | Purpose                                                           |
| ---------- | ---------------------- | ----------------------------------------------------------------- |
| `.gaai/`   | **Active**             | GAAI framework — backlog, delivery agents, project governance     |
| `.claude/` | **Active**             | Claude Code configuration (settings, hooks, permissions)          |
| `.jules/`  | **Active**             | Jules agent memory files (bolt, palette, sentinel, resolver data) |
| `.Jules/`  | **Archived/Duplicate** | Legacy Jules uppercase alias — not referenced by active workflows |
| `.agent/`  | **Unknown**            | Unidentified agent runtime state — investigate before removing    |
| `.kiro/`   | **Experimental**       | Kiro AI IDE integration — not part of CI or governance            |

## Governance

All sprint planning, backlog management, and delivery loops should go through
GAAI (`/gaai-deliver`, `/gaai-status`). Agent directories other than `.gaai/`
and `.claude/` should not write to the main branch without human review.
