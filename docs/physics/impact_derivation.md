# Impact Model Sign Conventions

This note documents the narrow friction-spin convention used by the rigid-body
impact model.

## Contact Geometry

The clubface normal `n` points from the clubface toward the ball. The contact
point on the ball is therefore behind the ball center:

```text
r = -R * n
```

where `R` is the golf ball radius.

The tangential component of the clubface motion is computed from the relative
velocity:

```text
v_tangent = v_rel - dot(v_rel, n) * n
tangent_dir = v_tangent / ||v_tangent||
```

The friction impulse on the ball follows the sliding direction of the clubface
relative to the ball in this model:

```text
F_t = |F_t| * tangent_dir
```

## Spin Direction

The angular impulse on the ball follows the contact torque:

```text
tau = r x F_t
    = (-R * n) x (|F_t| * tangent_dir)
    = -R * |F_t| * (n x tangent_dir)
```

So the spin axis generated by tangential friction is proportional to:

```text
spin_axis = -(n x tangent_dir)
```

For the repository's default impact frame, `n = +X`. A clubhead moving upward
relative to the ball has `tangent_dir = +Y`, so the generated spin is `-Z`.
Reversing the tangential motion to `-Y` produces `+Z`.
